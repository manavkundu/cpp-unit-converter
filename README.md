# Engineering Unit Converter (C++)

A lightweight, console-based utility developed in C++ to perform accurate engineering conversions for pressure, stress, and temperature.

## Features
- **Pressure & Stress:** Converts between Pascal (Pa), Bar, and Megapascal (MPa to N/mm²).
- **Temperature:** Converts between Celsius, Fahrenheit, and Kelvin scales.
- **Formatted Output:** Uses standard I/O streams and `<iomanip>` for clear CLI readouts.
